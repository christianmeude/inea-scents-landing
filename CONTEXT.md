# Domain Glossary

- **Booking**: The act of confirming an event package, selecting specific scents, and processing payment. This transaction occurs *exclusively* within the mobile app. The landing page does not handle bookings.
- **Inquiry**: The primary conversion goal of the landing page. An inquiry is a request for an event consultation or quote, submitted via the lead capture form.
- **Signature Collection**: A curated subset of premium perfumes displayed statically on the landing page to tease quality. The full catalog is reserved for the mobile app.
